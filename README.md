*Tags: `ZFS` `DFIR` `Bash` `Forensic`*

**🚨 [Incident Response: Phishing e Account Takeover](https://github.com/felipe-xavier-cyber/incident-response-phishing)**
Análise e contenção de campanha de phishing (M365) que atingiu 350+ destinatários. Inclui Playbook de contenção, revogação de tokens OAuth e análise de IoCs.
*Tags: `Blue Team` `Incident Response` `M365` `Phishing`*

**🔍 [Email Header Analysis (Spoofing vs ATO)](https://github.com/felipe-xavier-cyber/Email-Header-Analysis-e-Investigacao-de-Spoofing)**
Investigação forense de cabeçalhos de e-mail para diferenciação entre spoofing externo e Account Takeover. Análise de SPF, DKIM, DMARC e metadados de roteamento.
*Tags: `Email Security` `DFIR` `SPF/DKIM`*

**🤖 [Claude Code Automação](https://github.com/felipe-xavier-cyber/claude-code-automation)**
Scripts e workflows de automação com Claude Code para análise de arquivos, geração de relatórios e resposta a incidentes.
*Tags: `Claude Code` `Python` `Automation`*

**🐧 [Proxmox Toolkit](https://github.com/felipe-xavier-cyber/proxmox-toolkit)**
Coleção de scripts para gestão de servidores Proxmox: backups, monitoramento e recuperação de VMs.
